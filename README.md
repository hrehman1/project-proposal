# Project Proposal

### Project title

BeatPlug

### What and why?

This software would provide a way for producers to share beats, and for artists to find and purchase them. It would be in the form of a social media platform, but only producers can post, while artists can comment and purchase.

### For whom?

This software is meant for beat producers and artists.

### How?

The system will allow producers to upload beats with prices, and allow artists to comment on beats, like beats, favorite beats, purchase beats, or follow producers they like.

### Scope

I believe this app would be well in scope, as the base app shouldn't be too difficult to design, but adding in the social media aspect will make it more challenging.
